# Case 11 Oracle

独立按本文件原文语义标注；未读取产品输出。

## 原子条件
- A1：提交近两年编号 1.9 的表。来源 P1-L02，原文：“近两年1.9号表”。
- A2：提交近两年编号 1.10 的表。来源 P1-L02，原文：“近两年1.10号表”。
- A3：提交近三年编号 1.9 的表。来源 P1-L03，原文：“近三年1.9号表”。
- A4：提交近三年编号 1.10 的表。来源 P1-L03，原文：“近三年1.10号表”。

## 显式操作符
- OR(A1, A2)，每组择一：来源 P1-L01“每组只需择一”，成员由 P1-L02“第一组”枚举。
- OR(A3, A4)，每组择一：来源 P1-L01“每组只需择一”，成员由 P1-L03“第二组”枚举。
- AND(S1, S2)：来源 P1-L01，原文：“以下两组材料均须提交”。

## 作用域
- S1 成员 A1、A2，二选一；依据 P1-L01“每组只需择一”和 P1-L02“第一组”。
- S2 成员 A3、A4，二选一；依据 P1-L01“每组只需择一”和 P1-L03“第二组”。
- S0 包含 S1、S2，且两组均须满足；依据 P1-L01“以下两组材料均须提交”。
- 两组重复出现的“（1）”“（2）”是各自局部分组编号，不合并作用域。

## 关系
- parent / confirmed：第一组含 A1、A2，第二组含 A3、A4；证据 P1-L02“第一组”与 P1-L03“第二组”。
- parent / candidate：无。
- parent / unresolved：无。
- scope / confirmed：S1 与 S2 是独立择一组，二者都须提交；证据 P1-L01“以下两组材料均须提交，但每组只需择一”。
- scope / candidate：无。
- scope / unresolved：无。
- reference / confirmed：无；1.9、1.10 是材料名中的编号，不是回指。
- reference / candidate：无。
- reference / unresolved：无。

## 分母定义（冻结，未执行）
严格统计只计 confirmed 原子条件；candidate/unresolved 进入复核，不计自动判错。遗漏分母 N=4；错误合并分母为 N 个原子两两组合数；错误拆分分母 N；作用域误归属分母为 N × S 个 confirmed 原子—confirmed 作用域二元成员判断，S=3（S0、S1、S2）。无对应分母时记 N/A。
