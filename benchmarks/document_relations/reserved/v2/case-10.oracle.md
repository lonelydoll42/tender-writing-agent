# Case 10 Oracle

独立按本文件原文语义标注；未读取产品输出。

## 原子条件
- A1：提交营业执照复印件。来源 P1-L01，原文：“营业执照复印件”。
- A2：提交开户许可证复印件。来源 P1-L01，原文：“开户许可证复印件”。
- A3：某一复印件须加盖公章；被指对象无法唯一确定。来源 P1-L02，原文：“该复印件必须加盖公章”。

## 显式操作符
- AND(A1, A2)：来源 P1-L01，原文：“须提交营业执照复印件及开户许可证复印件”。
- OR：无。

## 作用域
- S1 confirmed 成员 A1、A2；依据 P1-L01“须提交……及……”。
- A3 对 A1 或 A2 的作用域 unresolved，不把它静默复制到两者，也不擅自只分配给一个。

## 关系
- parent / confirmed：A1、A2 由同一提交句统领；证据 P1-L01：“须提交……及……”。
- parent / candidate：A3 可能修饰 A1 或 A2；证据 P1-L01 两个“复印件”先行项及 P1-L02“该复印件”。
- parent / unresolved：无法唯一选定 A3 的父对象；同一句含两个可匹配的复印件。证据 P1-L01：“营业执照复印件及开户许可证复印件”与 P1-L02：“该复印件”。
- scope / confirmed：A1、A2 同属 S1；证据 P1-L01：“须提交……及……”。
- scope / candidate：A3 可能在 A1 或 A2 的材料范围内；证据 P1-L01 的两个复印件与 P1-L02“该复印件”。
- scope / unresolved：A3 的成员归属未解；不得把一个指代改成对两份材料都加盖。证据 P1-L02：“该复印件”。
- reference / confirmed：无。
- reference / candidate：A3 的“该复印件”候选先行项为 A1、A2；证据 P1-L01：“营业执照复印件及开户许可证复印件”。
- reference / unresolved：先行项无法唯一解析；证据 P1-L01 的两个复印件名词与 P1-L02 的单数指代“该复印件”。

## 分母定义（冻结，未执行）
严格统计只计 confirmed 原子条件；candidate/unresolved 进入复核，不计自动判错。遗漏分母 N=2；错误合并分母为 N 个原子两两组合数；错误拆分分母 N；confirmed 作用域数 S=1，作用域误归属分母为 N × S 个 confirmed 原子—confirmed 作用域二元成员判断。A3 的指代/作用域进入复核，不进入严格分母。
