# 边界证据合同 v1

本合同先于新样例冻结及实现任务建立。它是有限语法的评分合同，不是产品解析完整性声明，也不以 case-11 的通过率作为制定规则的依据。

## 三类职责

1. **操作符证据**：证明本组的 AND 或 OR 由哪一处明确指令授权。材料名、分号、句号、相邻组的指令不能代替该指令。同一原文片段可以承担多种职责，但每种职责必须分别验证。
2. **成员范围证据**：证明每个直接成员属于哪一组。需要明确组名或外层组数/范围指令、每个直接成员的来源、正确的直接 children 和 scope targets。嵌套组的直接成员仍是子组，不能用全部后代叶子替代。
3. **终止边界证据**：证明组的材料清单在何处结束。本有限语法使用最后一个成员之后的明确句末标点；外层组还需要每个直接子组各自的终止证据。上层操作符指令不必重复出现在组内 termination 引用中，也不能单独替代终止证据。

引用首先必须通过原始文档身份、版本、页号、精确字符区间、引文及行号校验。证明匹配使用同一位置的区间包含，不能用同页同字、关键词子串或相似度替代。有效的大区间可以覆盖较小的证据区间，但不得跨出该职责允许的区域。

## 有限适用范围

本版本支持同一页上由外层显式指令引出的连续命名组，组标签按第一组、第二组等唯一递增；每个子组在一行内使用冒号引出材料，材料可以用分号及连续括号编号区分，末尾必须有明确句末标点。空行不打断连续性；非空独立段落、章节、分页或额外未声明组打断继承范围。

局部明确指令也可以直接证明子组操作符。原 `1.0.4` 其余场景继续按旧规则评分，本合同不暗中重新解释 attribute、contextual、跨页、K-of-N 或 REQUIRED 语义。对冻结 14 例的覆盖由独立 sidecar 明确列出，不改写旧 oracle 的 `boundary_basis`。

## 合法继承

继承仅限上层明确适用于**每组**的单项选择指令，必须同时满足：

1. 上层完整指令及子组组名可在原文定位；声明组数与唯一、连续组标签一致。
2. 实际上层逻辑节点、operator relation 和 scope relation 均 confirmed，且直接 children 与声明的子组一致。非空结构 parent ID 或 candidate 父级不构成授权。
3. 子组存在 confirmed、带非空 basis 的 typed semantic parent 关系，明确指向该实际上层节点；该关系引用上层范围指令及自身组名。指向相邻组、仅 structural_list、来源缺失或存在额外冲突父级均不能确认继承。
4. 本组组名到冒号之间没有相反 AND、否定或未支持的选择数量。冲突不自动决定谁优先，应进入 candidate/unresolved；外层完整关系同步复核。
5. 上层到子组之间没有未获授权的独立段落、页界或新章节；子组成员和终止证据只能来自自身局部范围。借用另一组相同字样或同样的句号仍不合法。
6. 上层指令只能授权操作符；不能继承成员身份或终止句号。上层终止引用可汇集其直接子组的局部终止证据，但不得汇集未声明相邻组。

## 必须拒绝确认的情况

- operator relation 无指令依据、candidate，或借用相邻组指令。
- 成员少引一项、多引相邻组、scope targets 指向后代叶子而非直接子组、scope relation 非 confirmed。
- termination 只有上层指令、只有组内分号、只有材料名、只有相邻组句号，或覆盖到独立段落/下一组。
- 继承父级未确认、未明确包含本组、引用不足、标签/组数不符、局部冲突或不支持的数量。
- 源引用身份、版本、精确位置不一致；调用者自报 `_raw_coordinate_valid=true` 无效。

## 评测与发布纪律

先冻结本文及机器规则，再冻结开发可见正反例和验收侧新增未见文件，最后下发实现。新增未见文件在开发阶段禁止读取，共享文件系统仅属策略隔离，不宣称技术盲测。验收侧不得根据产品结果修改已冻结答案；失败及后续公开追加回归分别保存。

新旧评分器读取同一份已存储产品 graph/context/runtime，逐项报告状态、原子、成员、操作符及边界差异；原始输出、历史 `9/14` 报告不改写。若产品本身缺少合同要求的证据，不能通过评分器补造；修改产品和评分变更须分别记录。

正例应通过却被拒绝计为评分误阻断；错误 confirmed 关系被接受计为评分误接受。产品实际执行失败、未执行单列。它们不是企业材料的业务误阻断/误放行率。本批不调用真实模型、不补企业材料评测；旧公开 `0/8`、通用完整性与生产验收未通过、`partial/manual_review` 及 `uv.lock` 独立处理的边界保持不变。
